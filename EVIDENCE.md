# Evidence for the public source preview

This file summarizes the checks run on this preview before publication. It
contains sanitized decisive outputs only. The raw logs stay outside the public
tree because they carry local paths. Nothing here is native acceptance evidence:
**0 of 35** acceptance rows are proven natively at this preview, and A03, A16 and
A17 have no receipt at any revision (see [specs/ACCEPTANCE.md](specs/ACCEPTANCE.md)).

## Binding

- **Content:** every tracked file is listed with its SHA-256 in
  `SOURCE-MANIFEST.sha256` (generated by `scripts/build-source-manifest.py`; check
  with `python3 scripts/build-source-manifest.py --check`).
- **Source baseline:** derived from private source revision
  `053ae098813173acecda0e99b12527a191f3e8a6`. That revision is the frozen archive;
  it is not this repository's commit and is not public.
- **Method:** every check below ran on a fresh clone of this repository's single
  preview commit, not on a working copy. Suite counts are read from each suite's
  own pytest or Vitest summary.

## Found and fixed during pre-publication verification

- **Runner exit status.** An earlier `scripts/run-offline-tests.sh` read
  `PIPESTATUS` after a `local` declaration, so a failing suite was reported as
  passing. Fixed; `tests/unit/test_offline_runner.py` fails against the old
  runner and passes against this one.
- **Desktop test race.** Two pane tests asserted a `/status` request in the same
  render that displayed the verified instance; the request is issued by a later
  effect. They now wait for the request with the same assertion. Product code was
  not changed.
- **Storage burst diagnostic.** In one earlier candidate run with the same product
  code, `tests/unit/test_storage_latch_diagnosis.py` failed once on a heavily
  loaded host. It is kept unchanged and disclosed in
  [KNOWN-ISSUES.md](KNOWN-ISSUES.md) ("Load-sensitive storage diagnostic").
